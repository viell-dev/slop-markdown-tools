# mdrefine 0.1.0-beta.1

First public beta of Markdown Tools. npm package: `mdrefine`; executable:
`mdtools`. Requires Node.js 22.12 or newer.

## Features

- Separate lint and format commands with JSON reports, diff previews, stdin,
  check mode, and explicit file writes.
- Configurable presets, per-file overrides, suppression comments, and custom
  JavaScript rule and syntax plugins.
- Source-preserving formatting for CommonMark, GitHub Markdown, and Obsidian,
  with a default wrap width of 80 columns.
- Local link and fragment validation, verified link path and notation changes,
  GitHub tables and alerts, and Obsidian wikilinks, embeds, callouts, and block
  references.
- Obsidian paragraph reflow requires verified `strictLineBreaks: true`.

## Packaging and maintenance

- The package name changed from the unpublished `@viell-dev/markdown-tools`
  checkout name to `mdrefine`. Update library imports; the `mdtools` command,
  configuration names, and suppression directives remain unchanged.
- Installed package checks cover the command shim, library exports, and public
  TypeScript declarations on the supported CI platforms.
- Manual release preparation retains a tested tarball and checksum. Publishing
  is separately gated and uses the npm `beta` channel.
- PR-based maintenance applies to prereleases as well as stable versions.
- Multiline inline code is preserved during reflow instead of triggering an
  unsafe-format rejection.

## Known limits

The plugin API and configuration are provisional. Ambiguous links are reported
without guessing; unsupported syntax is preserved conservatively. Not every
Markdown layout is normalized. Review the
[design and limitations](https://viell-dev.github.io/slop-markdown-tools/design.html)
before adopting the beta across a vault. This project is developed and
maintained by agents without assumed human review.
